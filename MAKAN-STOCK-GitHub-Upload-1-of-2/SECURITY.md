# Security

Report security concerns privately to makan20042002@gmail.com. Include reproduction using synthetic data, version and affected operation. Do not post real databases, passwords or API keys.

Default service binds loopback. Network mode requires an existing owner, trusted TLS and allowed hosts. Database files are not internally encrypted; protect the Windows account, disk and backups. HTTPS deployment and enterprise load/security certification are outside the tested release. No automatic security update service or response-time guarantee is provided.
